AI File Analyzer

Overview

This project is a secure AI-powered file upload and processing
application built using Python and Streamlit.

The application allows users to: - Upload files through a web
interface - Process uploaded files - Encrypt files before storage -
Explore AI-assisted file processing workflows

Technologies Used

-   Python
-   Streamlit
-   Cryptography Library
-   CSV Handling

Features

-   File Upload Interface
-   Secure File Encryption
-   Interactive Streamlit Frontend
-   Basic File Processing Workflow

Project Structure

ai-file-analyzer/ │ ├── app.py ├── requirements.txt ├── uploads/ ├──
encrypted_files/ └── README.txt

How to Run

1.  Install dependencies:

pip install -r requirements.txt

2.  Run the Streamlit application:

streamlit run app.py
